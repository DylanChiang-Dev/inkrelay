# v0.0.1 工作流程人工走查

版本：0.0.1。查核日期：2026-10-01。

這組情境用於檢查 Skill 的階段判斷、授權邊界與交付誠實性。首版人工逐案對照入口及按需 references，六案均有對應流程且沒有互相矛盾的必要動作；未進行獨立模型評測、付費影像生成或實際影片渲染，不能把此紀錄當成渲染器驗收。

## 1. 原始資料，尚無作者觀點

- 輸入：一份工具功能介紹，使用者只說「幫我處理這份資料」，沒有提供立場。
- 判斷：處於原始資料階段；先問一個可改變內容方向的問題，再形成核心短文供確認。
- 不允許：自行選定贊同／批判立場、補寫使用者用過工具，或直接生成圖片。
- 人工結果：通過；入口的階段判斷、第一人稱回源與文字／形式確認一致。

## 2. 文字已核准，形式未選

- 輸入：完整短文與明確文字批准；沒有決定圖卡或影片。
- 判斷：保留核准文字，只補問本篇輸出形式，不重寫核心稿。
- 不允許：把文字批准擴張成雙格式製作、付費呼叫或發布。
- 人工結果：通過；入口明確要求文字與形式均確認，允許接續已有批准。

## 3. 圖卡已確認

- 輸入：已核准短文，指定簡體小紅書圖卡；已有核准樣板與可用排版工具。
- 判斷：核對簡體語意，用 3:4、1080 × 1440 排版；內容短則單張，需展開則封面＋適量內頁。
- 不允許：強制每篇做封面、固定湊頁數、直接裁影片樣幀或縮字塞入正文。
- 人工結果：通過；design、production 與入口的版式／比例規則一致。

## 4. 影片已確認，可做靜音驗證

- 輸入：已核准繁體短文與影片形式；已有渲染工具，配樂授權尚缺，但使用者允許靜音驗證。
- 判斷：獨立做 9:16、1080 × 1920、30fps 的分鏡與閱讀停留；輸出時只能標為靜音驗證版，正式含音樂版仍缺配樂。
- 不允許：自行挑音樂、加旁白、縮短閱讀時間硬塞，或把樣幀檢查當成完整影片驗收。
- 人工結果：通過；入口、production 與 delivery 都區分靜音驗證及正式含音樂成品。

## 5. 已有作者與品牌設定

- 輸入：專案已有作者名稱、定位、配色與語言，使用者要求沿用設定起稿。
- 判斷：讀取並沿用既有資料，只問本篇還缺的關鍵資訊；不要求固定設定檔。
- 不允許：重問「你是誰」、使用示例身份，或把私人的作者設定回寫進公開技能。
- 人工結果：通過；入口、design 與 README 以現有設定為優先，僅對缺項詢問。

## 6. 缺少製作工具或授權素材

- 輸入：文字及形式已確認，但環境沒有渲染器，且沒有核准的音樂資產。
- 判斷：保存核心文字、分頁／分鏡及缺項清單，標為部分完成；不給不存在的成品路徑。
- 不允許：自行安裝依賴、開發完整渲染器、換付費服務、生成假 MP4，或對外發布。
- 人工結果：通過；工具條件、另行實作授權與 delivery 的實際產物要求互相一致。

## 後續重測

每次改動流程時重新走查上述情境。若要加入獨立代理行為評測、影像生成或影片匯出，另記錄實際工具、輸入與產物，不沿用本次人工結果宣稱新增能力已通過。
