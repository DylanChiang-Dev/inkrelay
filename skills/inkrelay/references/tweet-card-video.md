# X／Twitter 推文卡片式影片

這是一種影片視覺模式，不是 X 客戶端、發布工具或推文擷取 API。只有使用者明確要求時才採用；不把所有影片改成社群介面，也不覆寫圖卡的品牌與 3:4 版式。

## 先沿用真實身份資料

需要已確認的 **顯示名稱、handle、頭像**，以及核准的正文與影片形式。先查專案或對話已有的作者／公開帳號設定，不重問已知身份。

- 使用者提供自己的個人頁，可在允許範圍內讀取一般公開網頁的名稱／頭像資訊；取得不到時說明缺項，只請他補必要資料或帳號截圖。
- 名稱或頭像只能來自使用者確認的資料或對應公開頁；不要從 handle 猜名字、拿搜尋到的同名人物、任選私人物件照片或生成臉孔代替真實頭像。
- 只保存所需身份與素材來源、取得日期、原始檔案／雜湊，不收集粉絲數、追蹤數或其他無關資料。來源素材依目標工作區規則保存。
- 頭像、個人帳號及品牌設定放使用者的工作區，不複製到公開 Skill。此模式不要求固定設定檔、特定用戶或機器路徑，也不取得登入、平台 API 或發布授權。
- handle 保留原拼字；署名／帳號名稱按已確認的身份呈現，不能因繁簡適配擅自改名。正文語言與身份字標可以分別處理。

## 9:16 卡片畫面

沿用既有影片規格：1080 × 1920、30fps。可用深灰背景與白色卡片作起步建議，或沿用使用者已指定的主題；這不是已核准的永久預設。

- 卡片身份區：真實頭像、顯示名稱與 `@handle`，各段換頁時保持位置與比例一致。
- 卡片正文區：用實際字型排字，先檢查全文能否在單頁保持可讀字級；能容納就保持全文同頁，不強制三頁。需要分段才換頁，不縮成極小截圖或把圖卡拉伸成影片。卡片可按版面整體水平／垂直置中，仍須檢查邊距與平台遮擋。
- 可選媒體區：只有本篇已有實際採用且用途明確的圖片／影片才放；獨立處理裁切、播放與文字安全區。沒有素材就完全移除，不填重複正文的占位圖、假播放器或與內容無關的示意影片，不為模仿參考抓取他人內嵌影片。
- 外層只保留影片需要的留白與背景，不複製手機時間、電量、短影音平台導覽列、播放進度、按讚／分享按鈕或「原聲」標籤。
- 作者資料可固定，內容換頁或媒體播放仍按實際分鏡安排；保留重要文字在手機上可讀且避開平台遮擋的位置，不承諾一組邊距能適用所有平台。

## 不把界面當成社群證據

- 預設不畫藍勾、認證、粉絲數、按讚、轉發、留言或其他數字；呈現真實資訊須有來源及採用決定。本人明確要求尚未生效狀態的樣式提案時，可以在獨立預覽呈現，交付須清楚說明是假設樣式而非實際帳號狀態；不能因計畫購買會員就把身份紀錄改成已取得標記，或把提案當已發布／已驗證的證據。
- 未發布的正文是創作稿，不補假時間戳、原文連結、發布狀態或「來自 X」的證明。推文風格不代表它已在 X 發布。
- 不以模擬界面代替使用者真正的帳號操作，不自動發布或修改第三方資源；圖片上的來源／日期是否顯示依使用者設定，不因此刪除內部來源紀錄或必需的 AI 內容揭露。

## 製作與交付

在文字與影片形式確認後，先以頁面規劃列出固定身份區、各段正文、可選媒體、閱讀停留與換頁方式。可以像串文一樣分成數張卡片，但不強制 2–3 張或固定時長，不新增作者立場。

使用環境已有的前端／影片工具與核准素材；不為此模式另建網站、下載依賴或新增完整渲染器。需要工程實作時另有相應授權才做，沒有工具時只交付分鏡及缺項，不編造 MP4 或預覽網址。

要求預覽時沿用已有影片預覽工具，不因提供帳號連結就自行匯出成片、生成付費旁白、開外部通道或發布。正式匯出仍需本篇授權，音樂仍遵守原有使用範圍與署名條件。

按 [交付檢查](delivery.md) 做兩輪檢視，另外核對身份區真實、換頁前後一致、媒體不壓正文、沒有非必要平台 UI 或假社群數據。圖片樣幀正確不等於完整影片播放、音訊與閱讀節奏已通過驗收。
