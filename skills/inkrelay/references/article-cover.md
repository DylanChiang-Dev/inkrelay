# 長文共用橫向封面：直接生成

用於使用者要求本篇公眾號封面／X 貼文附圖時，產出真實圖片，不只交一段要他搬到其他工具的提示詞。這不是 X 個人頁橫幅、自動發布或一鍵渲染器；不要求先製作平台稿才能明確試作封面。

## 來源版本與本篇授權

先讀最新核准全文與既有作者／視覺設定，選擇一個具體的場景、動作、人物關係或物件，能承載文章核心問題；不拼進每節所有概念、不預設晶片、筆電或霓虹腦圖。

使用者說「文字確認了，用已選工具／API 生成一張共用封面」時，授權已含當篇一次生成，不反覆問同件事。只要求過稿時不自動出圖；草稿未確認但本次明確要求試作時，記錄來源版本並標「候選封面」，不將生成授權當作者文字批准。

一次出一張，不自動開付費批次、改模型或重試；首次失敗或需要額外付費重生成時說明具體問題，按本次已有明確範圍處理，超出就先詢問。格式後製可以本地無損／等比處理，但不能藉裁切隱藏缺件。

## 代理組合提示詞，沿用系列風格

提示詞由代理直接讀取本篇全文、相關聊天中已確認的文章重點、公開邊界與系列視覺設定後組合，不要求使用者自行寫提示詞、貼全文到另一個介面或每篇重新選風格。未知事項不能靠推測補成作者立場，已有決定不重問。

每篇封面仍用影像模型重新作圖，而不是固定背景套版、沿用上一張只換文字或以程式形狀替代生成。系列的一致性在材質、光線、色調、視覺密度與編輯質感；具體主體依文章改變，不因統一風格讓每篇都放同一本書或同一台電腦。沿用已確認的設定，不自行改成另一套主題；提示詞只作內部可追溯紀錄，不要求使用者逐句編輯或確認它才能出圖。

生成前明確定義哪些物件／人物關係是理解主題不可缺少的核心，整組完整收進中央方形區內；左右只放可刪除的環境，不把必需物件放在橫圖兩端。

## 工具與既有憑證

優先使用環境可用且獲准的影像工具；使用者明確選 API 時，沿用他現有的 provider、端點與指定模型，先按既有機制確認可用性與憑證接入。不硬編碼模型、API host 或個人金鑰到公開 Skill。

如果本機有既有的影像生成 Skill／CLI，讀取其指引並原樣使用，不改 vendor 程式或另造 SDK runner。沒有可用工具就交付已完成的生成提示詞與缺項，明確說「尚未生成」，不替換成程式繪圖冒充模型圖片。

不要因 shell 沒有某個環境變數就斷定使用者沒有金鑰或模型不可用；先查允許的現有憑證／端點接入方式。憑證只在程序環境使用，不印出、不寫進提示詞、成品或生成紀錄，也不改動用戶憑證設定；仍需提供既有憑證時不索取第二組影像專用金鑰。

## 封面規格與內容

- 橫向 **寬:高 = 2.35:1**；若使用者說 1:2.35，先釐清方向，不生成錯誤直圖。可交付 2350 × 1000 PNG，或同一精確比例的其他尺寸；不要假定影像模型原生就支援這個尺寸。
- 中央 **1:1 是同一張圖的隱形構圖**，不是第二張圖或可見卡片。寬 W、高 H 的橫圖，其方形區是 x=(W−H)/2 到 (W+H)/2、y=0 到 H；2350 × 1000 的例子為 x=675 到 1675。全部核心主體／關係須完整位於此區，並留一點呼吸空間；左右只延伸可刪的環境。不能只以「還看得出是書」代替完整核心構圖，不畫框、裁切線、明顯接縫、分屏或畫中畫。
- 預設無字：不生成標題、作者、日期、來源、Logo、QR code、假界面數據或水印。有文字需求時另確認精確文字及排版方式，不放無法核對的引文。
- 保持單一具體場景，紀實攝影感或編輯插畫按文章選擇；縮成手機縮圖仍要辨認主體，不假裝是作者真實桌面、官方產品畫面或研究證據。
- 生成尺寸與比例不準時，先檢視構圖，再等比縮放與裁切到目標；不得拉伸物件、裁掉核心資訊或把小圖放大說成原生高解析。需要擴圖／重生成而增加費用時另確認。

## 一次生成，同圖派生橫圖與方圖

公眾號封面與 X 貼文附圖先共用同一張，不為每個平台重生成。X 的真實預覽若影響主體，才以本地裁切另存適配圖，不覆寫母圖、不聲稱所有平台都一定完整顯示。X 個人頁橫幅另有用途及布局，不自動沿用此圖。

從同一張橫圖的中央直接裁出 1:1，可另存方圖供轉發；這只是本機裁切，不重生成、不改主體。交付橫圖及方圖時說明它們是同一張母圖的兩種比例，原始橫圖保留不覆寫。

封面可以不含繁簡正文而共用；平台文字仍放文稿／貼文裡，不必嵌入圖片。素材所需的 AI 揭露依實際發布環境處理，不因畫面無字就省略。

## 檢視、保存與交付

核對實際檔案格式／尺寸、完整橫圖、中央 1:1 與非空白；以圖片檢視工具檢查每個必要物件是否完整、物件關係是否仍成立，以及是否沿用系列風格。中央切掉必要物件就標失敗／待修，不能把它交成「可直接用」的封面；不可畫個方框當作滿足安全區，也不能只量到比例就說構圖通過。

保存原始生成檔、實際提示詞、來源稿版本、所請求模型與工具、實際呼叫次數、後製方式、最終圖片與待審狀態，不保存金鑰或任何認證 header。依本篇既有 assets 位置存檔，不新增工程或獨立 viewer，也不把私人素材加入公開技能包。

支持圖片顯示的聊天直接展示真正的圖片，附可用檔案路徑，提示詞可以作紀錄連結但不是交付替代品。標明這是候選／待審封面；失敗或未檢視則如實說明，不能聲稱已發布。生成封面不取得上傳、排程、帳號操作或影片授權。
