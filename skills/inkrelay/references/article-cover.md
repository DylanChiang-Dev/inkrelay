# 長文完整封面：模型直接生成、按用途構圖

使用者要求本篇長文封面時，交付真實圖片，不只給待搬到其他介面的提示詞。這不是 X 個人頁橫幅、自動發布或固定渲染器；明確封面試作不要求先完成平台稿。

## 來源、標題與本篇授權

沿用最新核准全文、相關聊天、作者公開邊界與視覺設定，先找出文章的中心問題／論點，再選一個能表達它的場景、動作或物件關係。不能只看到「閱讀」就擺書筆，或看到「AI」就加晶片；不拼入每節全部概念、不新增作者經歷、成果或主張。

完成封面預設包含已核准文章標題。已有精確文字不重問，未確認時只補必要缺項；使用者明確要求無字才例外。指定繁體／簡體、精確標點與必要換行，不自行加副標、CTA、假引用或數據。署名／帳號只用於使用者明確選定的作者識別，沿用已確認文字與大小寫；沒有採用決定時留空，不以示例或公開帳號的存在代替封面使用授權，不附加頭銜、人像或認證標記。

當篇已明確要求使用既有工具／API 生成一張時，授權已含該次呼叫，不反覆問同件事。只過稿時不自動出圖；未核准草稿被明確要求試作時記錄版本並標候選，不補填正文批准。一次一張，不自動擴成雙版、批次或付費重試；超出已確認的費用／呼叫範圍先取得授權。

## 先對齊作者 IP，再寫視覺概念

先沿用專案與聊天中已知的作者定位、讀者、內容氣質及確認的視覺方向，不重問「你是誰」，也不以職稱或題材自動推定風格。把「讀者應感受到怎樣的作者」轉成排版、主體與視覺語言，再從本篇主旨挑一個可被看懂的視覺隱喻，而非堆物件或靠特效代表科技感。

使用者不滿現有方向且邀請討論時，先用文字提出少量真正不同的方向，說明各自的作者氣質與視覺取捨；只問仍會影響結果的選擇，例如畫面手法、配色或作者識別，不先生成多套付費樣稿。方向與實際樣稿已有確認就接續，不把風格問答變成每篇必經批准關卡。

提示詞以正向設計為主，順序為 **作者氣質 → 本篇論點 → 單一視覺隱喻 → 標題與版面 → 必要限制**。用確認的色彩、字型風格、材質、視覺密度與識別位置延續系列；具體主體依本篇改變，不把某個隱喻、配色或左右布局固定套到所有文章／作者。避免過量百分比及重複禁令讓概念變成機械排布，平台必需的比例與方裁切條件仍保留。

個人定位、姓名、handle、實際配色與核准樣稿留在使用者工作流；公開 Skill 只提供可設定的方法，不保存私人素材或硬編碼特定作者。

## 代理寫提示詞，模型完成整張設計

代理依聊天、全文、核准標題及確認的視覺方向組合提示詞；畫面、背景、文字、字體風格與排版由已選影像模型同次生成。**不先生成無字底圖再程式加字，不用程式修字、重排、拼背景或修補設計。** 本地工具只負責必要的呼叫、存檔、檢查與直接裁切，不能替代圖像創作。

每篇重新作圖，不沿用上一張固定背景只換標題。系列一致性可在色調、材質、光線、視覺密度及編輯語言，不要求每篇同一物件。沿用確認的方向；使用者要求換風格時，讓封面的字級、主體、對比與構圖一起改變，不只在舊畫面上添加裝飾。不把米白、柔光或保守留白當通用限制，也不把某篇高對比試作固化成所有人的品牌。

提示詞只需涵蓋本篇主旨、畫面如何表達、精確標題、確認風格與所選用途的構圖要求；不要求使用者逐句編輯或每次重新選風格。模型生成的字型外觀只是風格，不聲稱載入了真實字型檔。

## 繁體版與公眾號版分開判斷

- **繁體 FB／X 版**：完整橫向封面優先，沿用已選比例；沒有新指定時可沿用 2.35:1。標題與主體自由布局，不要求 1:1、不額外交付方圖，不因某個方裁切失敗標為該用途待修。
- **公眾號版**：寬:高 **2.35:1**，例如 2350 × 1000 PNG。圖內有一處能直接裁成完整 **1:1** 即可，左、中、右或其他合適位置都可，**不固定中央**。選定方區保留完整核准標題與表達主旨的核心畫面，不要求所有非核心裝飾都收進方區。
- 這是用途條件，不只由字形判斷：公眾號本篇即使明確改用繁體，仍需要可裁方區；簡體非公眾號圖不因此自動需要方圖。語言沿用本篇確認，不因封面流程增加未要求版本。
- 方區是同圖的隱形構圖，不能畫框、裁切線、可見接縫、畫中畫或分屏。可選區域 `(x, y, x+s, y+s)` 須在圖幅內；按實際構圖選座標，不套固定中心公式。不要把此段方區限制加入只做 FB／X 的提示詞。

兩版共用文章主旨與確認風格，但不強制同一張圖兼顧所有用途。已生成圖符合兩種用途時可直接沿用；需要分開生成時只在本篇相應授權範圍內執行，不能因「兩版」自行多呼叫一次。X 的真實平台預覽與個人頁橫幅仍分開處理，不保證所有平台都完整顯示。

## 工具與既有憑證

使用環境可用且獲准的影像工具；使用者明確選 API 時，沿用現有 provider、端點、指定模型及憑證接入方式，不硬編碼模型、API host、個人品牌或金鑰到公開 Skill，不自行換服務。

已有影像生成 Skill／CLI 時讀取其指引並原樣使用，不改 vendor 或另造 SDK runner。shell 缺環境變數不代表使用者沒有金鑰；先確認允許的既有接入方式，憑證僅在程序環境使用，不印出、保存或改動，不索取第二組影像專用金鑰。

沒有可用工具時保留已完成提示詞與缺項，明確說尚未生成，不改用程式繪圖冒充模型成品。

## 檢視、裁切與交付

1. 檢視實際橫圖與手機寬度縮圖：核對完整標題、採用的署名／handle、字形／標點、主旨與畫面的關係、閱讀層級、比例及作者氣質。沒有實際檢視不宣稱通過；字重、材質或構圖偏離要求時如實指出。使用者看過並明確接受樣稿後，將方向及實際基準留在本地供後續沿用；保留已觀察到的偏差，不將接受改寫成每項規格完全通過，也不為代理自己的審美擅自重生成。
2. 僅公眾號版另選取並檢視真實方裁切，記錄座標。某次中央裁切失敗，不等於其他位置也失敗；未試過的區域不能標通過。繁體 FB／X 不要求此項。
3. 所需方圖直接從同一張完成橫圖裁出，原圖保留，不重生成、不重新排版。文字錯誤或沒有合格方區時調整提示詞，在授權範圍內再生成；超出範圍先說明，不默默以程式補救。

尺寸不準時如實記錄原生尺寸與偏差，不拉伸、不把後製尺寸說成原生高解析，也不以裁切隱藏必要資訊。記錄原始圖、實際提示詞、來源版本、模型／工具、呼叫次數、裁切座標、實際檢查結果與待審狀態；不保存憑證。

沿用本篇 assets 位置，不新增 viewer 或第二套工程，不把私人文章、圖片或個人設定加入公開包。聊天可顯示圖片時直接展示實際產物及檔案路徑；提示詞不是成品替代物。素材所需 AI 揭露依發布環境處理。封面生成不取得上傳、排程、平台帳號或影片授權。
