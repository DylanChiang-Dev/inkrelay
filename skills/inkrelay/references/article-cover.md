# 長文封面：模型主視覺＋程式精確排字

只在當篇需要長文封面時使用本指引。交付的是實際圖片，不是只有提示詞；明確要求封面試作，不必先完成平台稿。本流程不建立固定渲染器，也不涉及 X 個人頁橫幅或自動發布。

## 從文章論點與作者定位開始

沿用最新核准全文、相關聊天、作者公開邊界及已確認的視覺設定，從文章的中心問題或論點設計畫面：選一個能表達關係、衝突或轉變的場景、動作或視覺隱喻。不要只因題目提到閱讀就擺書筆，或提到 AI 就放晶片；也不把各節概念全部塞進封面。畫面不得新增作者經歷、研究成果或正文未支持的主張。

核對標題、封面與正文是否承諾同一件事時，只在當篇有封面需求的情境載入 [writing-craft.md 的「標題與內容承諾」](writing-craft.md#標題與內容承諾)，不因這項連結讓其他寫作任務預先載入封面流程。

先接續已知的作者定位、讀者、內容氣質與核准樣稿，把「希望讀者感受到怎樣的作者」落到主體、色彩、材質、視覺密度及文字層級。不要由職稱或題材推定風格，不重問已有設定。作者 IP 是可設定的設計依據：姓名、handle、配色、樣稿與私人素材留在目標專案，公開 Skill 不寫入特定私人品牌或模型。

視覺概念以正向設計為主：**作者氣質 → 本篇論點 → 單一視覺隱喻 → 主體與文字空間 → 用途限制**。系列可延續色調、光線、材質與編輯語言，但每篇依論點重新創作主視覺，不沿用固定底圖只換標題，也不把一篇的配色、物件或左右布局套給所有作者。使用者要求換風格時，同時考慮主體、字級、對比與構圖，不只添加裝飾。

只有缺項會改變結果時才補問。使用者邀請討論新方向，可用文字提出少量真正不同的選項及取捨；不要建立固定問卷、先出多套付費樣稿，或把每篇風格確認變成新增的強制批准關卡。

## 精確文字與當篇呼叫範圍

完成封面預設含已核准文章標題；明確要求無字時才省略。已有精確文字就直接沿用，保留繁簡體、字詞、標點與指定換行，不擅自縮寫或增加副標、CTA、假引用、數據。未指定換行時可因版面斷行，但不改標題文字。署名／帳號只採用已明確選定的識別文字與大小寫；沒有採用決定就留空，不因帳號公開而自行放上封面，也不附加頭銜、人像或認證標記。

當篇已明確要求用既有工具／API 生成一張，授權涵蓋該次呼叫，不重複索取同一批准。只過稿或只寫提示詞時不呼叫影像工具；未核准稿被明確要求試作時，記錄來源版本及候選性質，不補填正文批准。

每篇預設一次呼叫、一張生成圖；本地排字與同圖裁切不增加生成次數。多用途不等於授權多張，不自動擴成雙版、批次或付費重試。需要再生成或另製用途版本時，先核對剩餘的已授權呼叫及費用範圍；沒有涵蓋就停在待處理並說明，不自行付費。

## 預設方法：生成主視覺，再用既有程式排字

影像模型負責主視覺與整體畫面創作，包括場景、背景、主體關係、光線及材質；既有本地排字／合成程式負責把核准文字精確放入畫面。這是預設分工，不是純程式海報，也不是讓模型生成文字後再蓋掉錯字。

- **生成前對齊構圖**：提示詞說明本篇論點、確認風格、主體關係、目標用途與預定文字空間。主視覺預設不生成正式標題、署名或替代文字；用構圖、明暗及視覺密度為排字留出自然位置，不畫占位字、方框或裁切線。需要公眾號方區時，主體與預定文字空間共同考慮該區域，不能等排完字才硬裁。
- **排字前確認條件**：沿用目標專案現有程式、版式設定與字體要求，不新增完整渲染器或第二套工程。確認實際載入的是採用的字體檔，驗證本篇繁簡文字、標點及識別文字的字形覆蓋，並檢視實際輸出，避免缺字、錯字與未察覺的替代字體。只有「程式指定了字體名稱」不足以證明載入成功。
- **本地精確合成**：保留原始生成圖，另存加入文字的最終合成圖。字級、字重、字距、行距、斷行、位置及文字對比可在本地修正，前提是保留精確核准文字、作者氣質與用途構圖。文字層及其必要的局部襯底可服務閱讀，但不能用大面積遮罩、拼背景或重繪來掩蓋不合格主視覺。

主視覺若論點不符、主體錯誤或構圖無法承載必要內容，先明確指出問題；排字不能把它變成合格圖。需重新生成時依當篇呼叫範圍處理，不用程式補畫冒充模型創作。尺寸偏差也不得靠拉伸或裁掉必要資訊隱藏。

缺少可用影像工具、既有排字程式或所需字體時，停止相應步驟，保留已完成部分並列明缺項；不自行安裝、換字體、改服務、改製作方式或以純程式圖冒充完成。原始主視覺已生成但尚未排字時，不稱為完整封面。

### 當篇明確選擇的其他方式

使用者可明確選擇讓模型直接生成整張封面，或沿用當篇指定的其他製作方式；接續該選擇，不強迫改用預設。模型直接整張生成時，提示詞包含精確標題、識別文字、字體風格及用途構圖，模型同次處理畫面與排版；模型呈現的字型外觀不等於載入真實字體檔。

其他方式仍須遵守精確文字、主視覺品質、用途、呼叫範圍及實際檢視要求。若當篇明確採純模型方式，不默默改為本地覆字；文字錯誤需再生成或改方式時，依既有授權及當篇選擇處理。工具或字體缺失不是自動改走其他方式的授權。

## 按用途決定比例與裁切

先辨認實際用途，再依目標專案既有要求與當次可查的規格選擇尺寸、比例及安全區。引用平台規格時記錄來源與查核日期；未查證就不宣稱是官方最新或永久規格。必要規格仍不明時只補該缺項，不拿另一平台比例代替。

- **FB 長文配圖／封面**：依本篇選定用途及目標專案要求製作完整橫圖；未設定時核對當次可查規格。不預設要求 1:1 方區或另交方圖。
- **X Articles 封面**：與 FB、公眾號、一般 X 貼文及個人頁橫幅分開處理。比例依目標專案的 X Articles 要求或當次可查規格，不把 2.35:1 當預設，也不套入公眾號方裁切限制。
- **微信公眾號封面**：本用途採寬:高 **2.35:1**，例如 2350 × 1000；這是此處的製作條件，不宣稱為永久官方規格。若當篇專案要求或查核規格有差異，先釐清所需交付，不冒稱沿用比例必然符合平台。橫圖內需有一處可直接裁成完整 **1:1**：左、中、右或其他合適位置都可以，不固定中央。該方區須保留完整核准標題與表達論點的核心畫面，非核心裝飾不必全收進去。

公眾號方區是同圖的隱形構圖，不畫框、接縫、裁切線、畫中畫或分屏。裁切座標 `(x, y, x+s, y+s)` 須在實際圖幅內，按畫面選擇，不套固定中心公式。「任意位置」表示可選合適位置，不表示每個位置都必須能裁出合格方圖。

用途不是由字形決定：公眾號即使用繁體，仍套用上述方區條件；簡體 FB 或 X Articles 不因此需要方圖。語言沿用當篇選擇，不新增未要求版本。多用途可共用論點與風格，合格同圖可沿用，但不強迫一張兼顧所有平台，也不因多用途自行增加生成呼叫。

## 沿用工具與憑證接入

使用已可用且獲准的影像工具。已有生成 Skill／CLI 就讀取其指引並沿用，不改 vendor、不另造 SDK runner。使用者選定 API 時沿用既有 provider、端點、指定模型與憑證接入，不把服務位址、模型、私人品牌或金鑰硬編碼到公開 Skill，也不自行換服務。

shell 缺環境變數不代表使用者沒有金鑰；先確認允許的既有接入方式。憑證僅在程序環境使用，不印出、保存或改動，不索取第二組影像專用金鑰。只有當篇生成需求與呼叫授權具備時才執行；修訂指引、檢查接入或準備提示詞本身不構成實際呼叫授權。

## 真正檢視，再交付

1. **先看主視覺，再看完成橫圖及手機寬度縮圖**：核對畫面是否表達核准論點、是否符合作者氣質；最終圖另查完整標題、採用的署名／handle、字形與標點、閱讀層級、對比及比例。預設合成方式同時核對實際字體載入與覆蓋結果。未實際開啟檢視的圖，明確記為未檢視，不宣稱通過。
2. **僅公眾號用途另驗方圖**：從最終合成橫圖選區，直接裁出並實際檢視，記錄座標。方圖必須來自同一張最終合成圖，不從無字原圖另排字，也不重生成或改排版來冒充同圖裁切。中央失敗不代表其他位置失敗，未試區域不能標通過。只做 FB 或 X Articles 時不要求此項。
3. **區分可修的文字與不合格的畫面**：預設方法的文字或排版問題可在本地修正後重新檢視；沒有合格方區時，可先評估不遮掩主體且保留完整文字的本地布局調整，再重新裁切。若主視覺本身不合格或無法承載用途條件，列明問題並依授權處理再生成，不用覆字掩蓋。當篇選定純模型方式則遵守其方法邊界。

保留原生尺寸及偏差；必要的合規尺寸處理要記錄方式，不拉伸，也不把後製尺寸說成模型原生高解析。使用者接受樣稿時，可把確認方向與實際基準留在本地，但仍保留觀察到的偏差；接受不等於各項規格全數通過，也不授權代理因個人審美重生成。

原始生成圖、最終合成圖及所需方裁圖分開保存。製作記錄包含來源稿版本、精確標題、實際提示詞、採用方式、工具／模型、呼叫次數、字體載入與覆蓋驗證（僅適用實際排字）、合成調整、原生及交付尺寸、裁切座標、已檢視項目與待處理問題，不保存憑證。純模型方式的完成圖可由原圖直接交付，不虛構程式合成或字體驗證。

素材與製作記錄沿用目標專案現有路徑及版本方式，不另造 assets 目錄、viewer 或第二套工程，不把私人文章、圖片與設定加入公開包。聊天支援圖片時展示實際產物及檔案路徑，提示詞不替代成品。素材 AI 揭露依目標發布環境處理；封面製作不修改預覽／發布狀態，不取得上傳、排程、帳號操作或影片製作授權。
