# InkRelay｜墨流

**v0.0.1 · 流程 Skill · MIT**

將原始資料或短文，整理成可審核的核心內容，再規劃圖卡與文字影片的製作、檢查及交付。

> 首版提供 Agent 工作流程與製作規格，**不是一鍵生成工具，也不包含固定渲染器**。圖片、影片及預覽依賴使用者環境中已有且獲准使用的工具；沒有工具時，交付已完成的文字與製作規劃並說明缺項。

## 首版能力

- 接續原始資料、未確認草稿或已核准短文，不重問已有的作者與品牌資料。
- 先確認核心文字與輸出形式，再安排封面、內頁或影片分鏡。
- 圖卡：3:4、1080 × 1440 PNG，支援單張或封面＋內容頁。
- 文字影片：9:16、1080 × 1920、30fps，獨立排版、換頁及閱讀停留時間；預設無旁白。
- 按需求製作繁簡版本；檢查文字、作者識別、可讀性、素材授權與實際成品。
- 作者、定位、語言、視覺風格及工具皆可設定；米白科技編輯風只是起步建議，不綁定任何人的品牌。

首版不附背景圖、字型、音樂、API 金鑰或第三方技能，不自動選題、使用付費服務、發布或排程，也不取代既有的長文轉影片流程。

## 安裝

具備讀取 `SKILL.md` 能力的 Agent 可使用本技能。Codex 可在目標專案的 `.agents/skills/` 發現技能；本機可用符號連結維持單一來源，也可在其他環境複製完整的 `skills/inkrelay/` 目錄。

在目標專案根目錄執行以下指令，使用已發布的版本；若已有同名倉庫或技能，先確認既有內容，不覆寫或刪除：

```sh
(
  set -eu
  if test -e inkrelay || test -L inkrelay ||
     test -e .agents/skills/inkrelay || test -L .agents/skills/inkrelay; then
    printf '%s\n' '同名倉庫或技能已存在，請先確認，不覆寫。' >&2
    exit 1
  fi
  git clone --branch v0.0.1 --depth 1 https://github.com/DylanChiang-Dev/inkrelay.git inkrelay
  mkdir -p .agents/skills
  ln -s "$(pwd)/inkrelay/skills/inkrelay" .agents/skills/inkrelay
)
```

若倉庫已下載於其他位置，將連結來源改為那份倉庫的絕對路徑。請連結整個技能目錄，不只連結 `SKILL.md`，以保留 references 與 UI metadata。技能未出現在清單時，重新載入 Agent 工作階段。

技能命名與發現方式的官方說明：https://developers.openai.com/codex/skills/

## 呼叫範例

```text
使用 $inkrelay 處理這份資料，沿用已有作者與品牌設定，先給我核心短文過稿，暫不製作圖片或影片。
```

```text
使用 $inkrelay。核心文字已確認；這篇要小紅書簡體圖卡，請先規劃封面與內頁，再使用已有且獲准的樣板製作。
```

```text
使用 $inkrelay。文字與影片形式已確認，請規劃繁體 9:16 文字換頁影片；沒有授權音樂時只交付靜音驗證版，不發布。
```

## 工具與設定

純文字起稿、分頁與分鏡規劃不需要本倉庫的 npm 或 Python 依賴。實際製作前，Agent 必須確認可用工具及本篇授權範圍：

- 靜態圖片可使用既有排版、截圖、渲染或影像生成工具；正式文字優先由可控的排版工具處理。
- 影片可使用既有 Remotion 或其他影片製作工具；本 Skill 不捆綁、不自動安裝這些工具。
- 字型與音樂由使用者提供或在獲准範圍內查核取得；不得把特定平台曲庫的權利延伸至所有平台。
- 影像模型及 API provider 沿用使用者設定，不硬編碼、不自行替換；有費用的呼叫須確認授權。

作者名稱、定位、主要語言、視覺樣板、平台及輸出形式可從專案資料或對話取得，不必為使用本 Skill 建立特定設定檔。缺少資料時，只詢問會影響本篇工作的必要項目；示例不是作者資料。
